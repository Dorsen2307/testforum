# Test Forum
Тестовый проект форума для тренировки

## Стек
PHP, MySQL, Smarty, JS, JQuery

## Как запустить локально
1. Клонировать `git clone` в папку доменов вашего локального сервера
2. Импортировать приложенный файл БД `testforum.sql` через кнопку импорт в phpMyAdmin
3. Запустить сервер и открыть в браузере домен

## Описание
- Точка входа проекта находится в `index.php`
- Проект построен на паттерне MVC
- Используется шаблонизатор Smarty
- `config.php` в папке config содержит настройки проекта
